# DentAcademy System

Apprenticeship management system with AI dropout prediction, attendance tracking, and notifications.

## Repo Structure

- `dentacademy-backend/` — FastAPI + SQLAlchemy + MySQL API
- `dentacademy-frontend/` — React + Vite + Tailwind UI

## Getting Started

### Backend

```bash
cd dentacademy-backend
pip install -r requirements.txt
# create the database, then:
python seed.py   # creates schema + demo data
uvicorn main:app --reload
```

### Frontend

```bash
cd dentacademy-frontend
npm install
npm run dev
```

App runs at http://localhost:3000

## Default Login Credentials

Login uses the **username** (not email).

| Role | Username | Password |
| ---- | -------- | -------- |
| Admin | `admin` | `Admin@1234` |
| Supervisor | `supervisor` | `Super@1234` |
| Mentor (any) | generated per user | `Mentor@1234` |
| Apprentice (any) | generated per user | `Apprent@1234` |

Mentor and apprentice usernames are generated by the seed script as `firstname.surname<number>` (e.g. `thabo.nkosi1`). You can find the full list of generated users in the database after running `seed.py`.
